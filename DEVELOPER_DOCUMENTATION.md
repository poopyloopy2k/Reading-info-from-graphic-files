# Документация разработчика

## Текст программы

### Наименование программы

**ImageInfoReader** — приложение для извлечения информации о графических файлах, разработанное с использованием Qt.

### Область применения

Программа предназначена для извлечения и отображения основных характеристик графических файлов, таких как размер, разрешение, глубина цвета, тип сжатия и другие параметры. Поддерживаемые форматы: JPG, GIF, TIF, BMP, PNG, PCX.

### Назначение программы

- Чтение и анализ графических файлов.
- Вывод информации о файлах в виде таблицы.
- Поддержка пакетной обработки до 100000 файлов.
- Отображение дополнительных характеристик (например, количество цветов для GIF).

### Структура программы

- **main.cpp**: Точка входа в приложение.
- **MainWindow.ui**: Файл интерфейса пользователя, созданный в Qt Designer.
- **MainWindow.h и MainWindow.cpp**: Логика пользовательского интерфейса и обработки изображений.
- **release/**: Содержит собранный исполняемый файл ImageInfoReader.exe.

### Используемые библиотеки и модули

- **Qt**: Библиотека для создания графического интерфейса.
- **QImageReader**: Для работы с графическими форматами (JPG, PNG и т.д.).
- **QFileInfo**: Для получения информации о файле.
- **QTableWidget**: Для отображения информации в таблице.
- **QDir**: Для работы с каталогами и файлами.

### Основные функции

- **#chooseAFolder**: Открывает диалоговое окно для выбора папки с изображениями. После выбора папки путь отображается в метке на интерфейсе, и пользователь может продолжить анализ.
  
- **#startToAnalize**: Инициализирует процесс анализа изображений в выбранной папке. Извлекаются метаданные каждого изображения, включая имя, размер, разрешение (DPI), глубину цвета и тип сжатия (если доступно).

- **#updateTable**: Обновляет таблицу на интерфейсе, отображая информацию о файлах. Реализована пагинация, каждая страница отображает 17 файлов.

- **#prevPage** и **#nextPage**: Функции для переключения между страницами результатов. Это позволяет пользователю просматривать информацию о файлах по частям.

---

### Структура данных

- **#FileInfo**: Структура, которая хранит метаданные изображения, такие как имя файла, размер, разрешение, глубина цвета и тип сжатия.

  ```cpp
  struct FileInfo
  {
      QString fileName;       // Имя файла
      QSize imageSize;        // Размер изображения
      int dpiX;               // Разрешение по оси X (DPI)
      int dpiY;               // Разрешение по оси Y (DPI)
      int depth;              // Глубина цвета (бит на пиксель)
      QString compression;    // Тип сжатия
  }; ```
### Взаимодействие с пользователем

- **#chooseAFolder**:
  - При нажатии на кнопку "Выбрать папку" открывается диалоговое окно для выбора папки на файловой системе.
  - После выбора папки в метке (`QLabel`) отображается путь к выбранной директории.
  - Если папка не была выбрана, в консоль выводится сообщение о необходимости сбросить текущий выбор перед новым выбором.
  - После успешного выбора папки становится доступна кнопка "Начать анализ", а также активируется индикатор прогресса.

- **#startToAnalize**:
  - При нажатии на кнопку "Начать анализ" запускается процесс анализа изображений в выбранной папке.
  - Информацию о каждом изображении (имя файла, размер, разрешение, глубина цвета, сжатие) извлекает программа и сохраняет в структуру `FileInfo`.
  - Прогресс анализа отображается в `QProgressBar`, которая обновляется по мере обработки изображений.
  - После завершения анализа пользователю показывается всплывающее сообщение с информацией о завершении процесса.

- **#updateTable**:
  - Таблица на главном экране обновляется для отображения результатов анализа изображений.
  - Каждая строка таблицы представляет собой информацию о конкретном изображении.
  - Для улучшения удобства восприятия данных, реализована пагинация, и в таблице отображается только ограниченное количество строк (по 17 файлов на страницу).
  - Номера строк таблицы соответствуют глобальному порядку файлов, а не только порядку на текущей странице.

- **#prevPage** и **#nextPage**:
  - Эти кнопки позволяют пользователю переключаться между страницами результатов.
  - Кнопка "Предыдущая страница" (`#prevPage`) перемещает пользователя на предыдущую страницу (если такая существует).
  - Кнопка "Следующая страница" (`#nextPage`) перемещает на следующую страницу, если это возможно.
  - Пагинация помогает избежать перегрузки информации на одном экране, обеспечивая удобное и понятное отображение больших объемов данных.

- **#messages**:
  - После завершения анализа выводится сообщение об успешном завершении операции через `QMessageBox::information`.
  - Если возникает ошибка при обработке файла (например, не удается загрузить изображение), выводится сообщение в консоль, но программа продолжает обработку других файлов.

### Пример взаимодействия:

1. Пользователь нажимает на кнопку "Выбрать папку".
2. Открывается диалог выбора папки, и пользователь выбирает директорию с изображениями.
3. После выбора папки активируется кнопка "Начать анализ". Пользователь нажимает эту кнопку.
4. Программа начинает анализировать изображения в папке, обновляя прогресс в `QProgressBar`.
5. После завершения анализа пользователю показывается сообщение, и таблица обновляется с результатами анализа.
6. Если изображений много, пользователю предоставляется возможность переключаться между страницами с помощью кнопок "Предыдущая страница" и "Следующая страница".

## Обработка ошибок

- Программа обрабатывает ошибки при загрузке изображений. Если не удается загрузить изображение (например, файл поврежден или не является изображением), выводится сообщение об ошибке в консоль, и программа продолжает обработку других файлов.
  
- При возникновении ошибок во время анализа (например, если файл не имеет метаданных или не удалось получить информацию о сжатии), выводится соответствующее сообщение, и программа продолжает анализ оставшихся файлов.

- В случае проблем с чтением данных о разрешении или глубине цвета, программа корректно обрабатывает исключения и продолжает работу.

## Дополнительные сведения

### Масштабирование изображений

- Для работы с изображениями используется класс `QImage`, который автоматически управляет масштабированием изображений в зависимости от их размера.
- Изображения масштабируются при необходимости (например, если изображение слишком велико для текущего размера экрана) с сохранением пропорций.

### Время выполнения

- Время выполнения анализа изображений и обновления таблицы может быть измерено с помощью модуля `QTime` в Qt.
- Время отображается в миллисекундах, что позволяет пользователю оценить скорость обработки изображений и сравнивать эффективность обработки больших и малых папок с файлами.
