# Пользовательская документация

## 1. Введение

Программа "Считывание информации из графических файлов" предназначена для извлечения основных данных из изображений в различных графических форматах.
Приложение поддерживает форматы JPG, GIF, TIF, BMP, PNG и PCX, и выводит информацию о каждом изображении в виде таблицы.

## 2. Системные требования

- Операционная система: Windows 7 и выше
- Программное обеспечение:
  - Qt 5.x или выше для работы с исходным кодом
  - Для использования исполнимого файла - Windows 7 и выше
- Аппаратные требования:
  - Минимум 2 ГБ ОЗУ
  - 100 МБ свободного места на диске

## 3. Установка

### 3.1 Установка с исходным кодом

1. Убедитесь, что у вас установлена последняя версия Qt.
2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/poopyloopy2k/Reading-info-from-graphic-files.git```
Откройте проект в Qt Creator.
Постройте и запустите проект.
### 3.2 Установка исполнимого файла
Скачайте архив ```release.7z.```
Распакуйте его на вашем ПК.
Запустите исполнимый файл ImageInfoReader.exe.
## 4. Использование приложения
Запустите приложение.
Выберите папку с изображениями для обработки. Приложение поддерживает работу с папками, содержащими до 100000 изображений.
Просмотрите информацию о файлах в табличном формате:
Имя файла
Размер изображения (в пикселях)
Разрешение (dot/inch)
Глубина цвета
Тип сжатия (если применимо)
При необходимости сохраните результаты в файл (опционально).
## 5. Пример использования
В папке "Изображения" находятся файлы форматов JPG, GIF, PNG.
Приложение автоматически выведет информацию о каждом изображении, включая его имя, размер, разрешение и другие характеристики.
