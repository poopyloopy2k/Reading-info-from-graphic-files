# Чтение информации из графических файлов

## Описание проекта

Этот проект представляет собой приложение, разработанное на Qt, для считывания информации из графических файлов различных форматов.

## Возможности

- Обработка файлов форматов JPG, GIF, TIF, BMP, PNG, PCX.
- Считывание информации:
  - Имя файла.
  - Размер изображения в пикселях.
  - Разрешение (dot/inch).
  - Глубина цвета.
  - Тип сжатия (если применимо).
- Дополнительная информация:
  - Матрица квантования для JPEG.
  - Количество цветов в палитре GIF.
- Пакетная обработка до 100000 файлов из одной папки.

## Установка

### Если у вас есть Qt на ПК и вы хотите иметь доступ к коду

1. Убедитесь, что у вас установлена последняя версия Qt Creator.
2. Клонируйте репозиторий:
   ```bash```
   ```git clone https://github.com/poopyloopy2k/Reading-info-from-graphic-files.git```
Откройте проект в Qt Creator.
Постройте и запустите проект.
### Без наличия Qt
В архиве release.7z находится исполняемый файл ImageInfoReader.exe, который можно запустить напрямую на Windows без необходимости сборки проекта.
Распакуйте архив на свой ПК и запустите приложение.
Использование
Запустите приложение.
Укажите папку с изображениями для обработки.
Просмотрите информацию в табличном формате.
При необходимости сохраните результаты в файл (опционально).
## Структура проекта
main.cpp: Точка входа в приложение.
MainWindow.ui: Файл интерфейса пользователя, созданный в Qt Designer.
MainWindow.h и MainWindow.cpp: Логика пользовательского интерфейса и обработки изображений.
release/: Содержит собранный исполняемый файл ImageInfoReader.exe.
